## 后续更新方法

1. 根据实际界面核对手册中的入口、按钮名、默认覆盖策略和导入行为。
2. 使用独立测试浏览器加载当前扩展，录入虚构数据；不要直接截取真实简历、API Key 或含身份参数的申请链接。
3. 实际执行选区、指定记录填写和复制流程，等待异步操作及界面动画完成后截图；不要仅写入 DOM 值来模拟成功。
4. 核对来源记录、目标记录、保留条目及最终字段值，再保存结果图。复制应检查实际复制的文本。
5. 按需替换 PNG，保持文件名稳定，更新手册步骤、图注、日期和本文件的版本基线。
6. 逐张查看截图，检查文字可读、无过渡动画残影、无真实个人数据；验证手册的图片和链接均能打开。

用于截图的浏览器配置、缓存和临时脚本不属于文档交付内容，无需提交。不要将本地演示截图写成某家招聘网站的兼容性证明。
